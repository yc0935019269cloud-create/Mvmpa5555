# 視光室 / THE REFRACTION ROOM

2026-10-15 · Unity 6000.6.5f1 / Blender 5.2 / Unity WebGL

## 體驗與空間

玩家是驗光師，WASD 在診間移動、滑鼠轉頭、E 操作眼前物件。F 靠近驗光儀進入第一人稱操作位置；Esc 釋放滑鼠，Tab 開病歷。診間為溫暖木紋、灰綠牆面、米白醫療設備。人物採有五官、服裝與手指的風格化成人模型，不以照片擬真作完成標準。

以公尺建模。患者眼睛到牆面視標 6.0m；患者面向 -Z，玩家由 -Z 看向患者，畫面左側為患者右眼 OD。綜合驗光儀位於玩家與患者之間，以立柱和支臂支撐。檢影預設工作距離 57 cm（1.75 D），可選 40–100 cm。

## 對應動作

| 行為 | 可見結果 |
| --- | --- |
| 消毒 | 拿酒精棉布：按壓 75% 酒精噴瓶噴在布上（霧粒子），依序擦額托、右／左面罩（由內向外繞圈，留下水光），再拿起 PD 尺正反兩面擦拭。驗光儀先轉開到一旁再擦 |
| 瞳距 | 驗光儀轉開，PD 尺放在鼻樑。①請受測者「看我的這隻眼睛」②檢查者閉右眼、用左眼看，受測者注視檢查者左眼，0 對準其右眼瞳孔右緣（顳側）③閉左眼、改用右眼看，讀左眼瞳孔靠右眼側（鼻側）邊緣。視角由實際眼位與尺面幾何計算（含視差）；之後 P.D. 旋鈕讓兩側鏡片筒移動 |
| 水平、桌高、頂點距離、鎖定 | 對應旋鈕、桌架、儀器位置與鎖柄移動 |
| 燈光 | 牆上開關撥動，室內照度改變 |
| 遮眼、針孔 | 頂部輔助鏡片旋鈕轉到 OC／PH，內部輔助鏡盤把遮片或針孔片轉入主窺孔 |
| 球面、柱面、軸 | 外側弱球面大轉盤（0.25D）、強球面環（3.00D）、下方同心內鈕柱面度數、外圈軸鈕；讀數窗（正黑負紅）、量角刻度與窺孔軸位指標同步。滑鼠指向旋鈕可滾輪或點擊直接操作 |
| 檢影 | 檢影鏡的光帶是一盞帶狹縫光罩的聚光燈，按住左鍵拖曳實際把光帶掃過臉部；瞳孔反射依該子午線殘餘度數順動／逆動／中和，近中和時更快更寬更亮；光帶不在主子午線時反射帶偏斜（破裂現象） |
| JCC | 轉盤（turret）把 JCC 轉入窺孔；A：翻面滾輪手柄與柱面軸同向，P：紅點與柱面軸平行；JCC 與柱面軸齒輪連動，翻面以手柄軸轉 180° |
| 視標 | 拿遙控器，牆面與控制顯示器同步換 E、紅綠、蜂巢 |
| 問答 | 患者張嘴說話、點頭、眨眼；中文字幕／瀏覽器語音 |
| 紀錄 | 拿板夾與筆，寫字動作後更新病歷，鏡片改動使紀錄失效 |

## 教學範圍及驗證界線

期中流程依使用者提供的期中紀錄單（2026-10-15）：九項前置；① 雙眼檢影＋工作距離，右、左眼以淨檢影值測 VA 並記錄度數與 VA（低於0.8做 PH）；② 右、左眼第一次 MPMVA 記錄度數與 VA 後做紅綠；③ 雙眼 JCC 結束後記錄度數；④ 雙眼第二次 MPMVA 記錄度數與最佳 VA。雙眼完成同一項才進下一項。保留教學／自由／考試（18分鐘）與可重現病例。使用者 2026-10-15 明確限定：只有期中範圍、不包含鐘面圖；新的遊戲不提供鐘面圖，也不加入雙眼平衡、AA、NPA、NPC。

光學以球面等效與雙角功率向量計算，不從任務步驟直接選預設答案。JCC ±0.25D、負柱面表示、柱面每增加 -0.50D 搭配球面 +0.25D 維持等效。紅清加負、綠清加正，兩邊等清回核 VA。檢影工作距離扣球面，不改柱面。

模糊畫面和受測者回答是教學近似模型，不能視為臨床預測；不模擬裂隙燈疾病診斷、眼底鏡、真實眼球波前或全部眼科檢查。源教材明列期末才擴充的雙眼平衡、AA/NPA/NPC 不冒稱已完成。

## 2026-10-15 遙控器與診間配置改版

小型升降桌取代右側大桌，驗光儀立柱與支臂、電腦螢幕及全部檢查工具集中於同桌。LiftDeck 驅動桌面與支臂升降；待機臂轉開 90°、驗光儀頭補償旋轉而保持朝前，轉入後恢復既有 6 m／12 mm 校準位置。

主觀驗光底欄縮減；檢影階段保留調鏡、WD 等操作。換表與列選擇移到常駐左下角遙控器。照片中的未支援視標不做假按鍵。JCC 外支桿採螢幕平面角度拖曳及放開吸附；鏡片中央點擊切 A／P，滾輪逐面翻轉，兩次翻轉登記一次比較。平板保留點支桿轉入／收回的替代操作。

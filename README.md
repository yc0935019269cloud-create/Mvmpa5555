# 視光診間 3D 練習 · 自覺式驗光

把「自覺式驗光完整流程整理」變成可以操作的 3D 診間遊戲。診間格局依手繪草圖:
受測者 → 綜合驗光儀 → 驗光師 → 6 m → 多功能可切換視力表,左上角投影機。

## 練習範圍(期中考)

前置檢查 → 檢影 → 給工作距離並記錄 → **OD、OS 各做一次**:
測 VA(< 0.8 加測 PH)→ 霧視 · 1st MPMVA → 紅綠檢查 → JCC(APA / PPAP)或鐘面圖 → 2nd MPMVA。
期末的雙眼平衡 / OU MPMVA / AA·NPA·NPC 之後再擴充。

## 三種模式

| 模式 | 內容 |
| --- | --- |
| 教學 | 13 個步驟,每步有目標、提示與過關條件;可看「受測者視野」(模擬模糊)與上帝視角 |
| 考試模擬 | 前置完成後開始 18 分鐘倒數;沒有提示;結束後逐項計分(前置 10 / 檢影 15 / 單眼各 30 / 紀錄單 5 / 時間 10) |
| 自由練習 | 不受步驟限制,隨時顯示實際處方與預測視力 |

每位受測者(編號)的屈光度、散光、受測者答案的猶豫與偏好(偏愛更負、偏愛紅色)都不同,同一編號會生出同一位受測者。

## 怎麼玩

- 點 3D 診間裡的**黃色熱點**,或用底下的視角列 / 右側(直放時在下方)操作台分頁:
  前置 · 驗光台 · 檢影 · 視力表 · 紀錄單 · 對話 · 速查。
- 拖曳 3D 畫面可以左右/上下看,雙擊回正。
- 檢影:畫面上會有光帶掃過瞳孔,依反射光「順動 / 逆動 / 中和」調鏡片(順加逆減),也可以直接用手指或滑鼠拖曳光帶。
- iPad / 手機請橫放使用最舒服;直放也可以操作。

## 模擬模型(給想知道「答案怎麼來的」的人)

- 屈光以功率向量 (M, J0, J45) 計算,殘餘模糊 B = √(M² + J0² + J45²),視力 logMAR = 最佳矯正 + 0.5 × (B − 0.1)。
- 過度負矯正會被調節補回去(所以 MPMVA 要「最大正度數」、視力不再進步就停)。
- 紅綠:紅 / 綠相差 ±0.25D 的色像差;過正偏紅、過負偏綠,散光殘餘會降低靈敏度。
- JCC:紅點 = 負圓柱軸;A 模式紅點在軸 ±45°、P 模式紅點 / 白點在軸上,翻轉比較兩片的模糊量。
- 檢影:殘餘 = 鏡片 − (真實處方 + 工作距離),< 0 順動、> 0 逆動;光條與殘餘主軸不對齊時反射光帶會歪斜(break)。

## 本機執行

```bash
npm start          # http://localhost:8080
npm test           # 光學核心單元測試 + 「模範學生」機器人跑 24 位受測者完整流程
```

純靜態網頁(ES Modules + 內建的 three.js r170),沒有建置步驟;部署只要把
`index.html`、`styles.css`、`src/`、`vendor/` 放到任何靜態主機。

## 部署到 GitHub Pages

repo 已附 `.github/workflows/pages.yml`。第一次需要在 GitHub:
**Settings → Pages → Build and deployment → Source 選 “GitHub Actions”**,
之後每次 push 到 `main` 會先跑測試再自動發佈。

## 目錄

```

src/sim/      optics.js(功率向量、JCC、視力) patient.js(受測者模型與答案) retino.js(檢影)

src/ui/       app.js(選單/步驟卡/結果) panels.js(操作台) retinoCanvas.js(檢影畫面)
tests/        sim.test.mjs  flow.test.mjs  bot.mjs
vendor/       three.module.min.js
```

# 視光室 / The Refraction Room

用 **Unity 6.6 + Blender 5.2** 重製的第一人稱驗光練習。玩家可以在診間走動、拿起工具、觀察眼睛與檢影反射、操作綜合驗光儀、翻轉 JCC、聽受測者回答並寫入紀錄。

**線上體驗：** https://yc0935019269cloud-create.github.io/Mvmpa5555/

電腦用鍵盤滑鼠；平板（建議橫放）可觸控：左下搖桿走路、拖曳畫面轉頭、點物件互動、坐近後直接用手指按住旋鈕沿圓周拖曳轉動（驗光儀完整露出，按鈕收在右下角）、手指拖曳掃檢影光帶，PD 步驟有按鈕。若平板沒自動切換觸控介面，網址加 `?touch=1`。

## 獨立練習模式（2026-10-26）

首頁右上方「全部練習模式」可進入新增的兩個 2D 模式；本機也可直接雙擊 `docs/modes/index.html`。

- **ACP-8 遙控器與投影機**：`docs/modes/remote.html`。使用提供的實物照片面板與 TOPCON A 型 30 圖卡原圖；投影幕置於遙控器上方，捲動時保留。43 個按鍵、選表、遮罩與方向移動、紅綠濾片、燈、P1/P2 程序編寫、RESET、程序前後、匯出／匯入與 10 分鐘熄燈。選表解除遮罩，遮罩邊界接續同類圖卡。P1/P2 初始空白，依手冊編寫；不虛構未公開的完整出廠程序。
- **2D 綜合驗光儀**：`docs/modes/refraction.html`。手動設定或隨機雙眼答案；雙眼檢影 → 扣 WD → VA 直接給值 → 完整右眼 MSR → 完整左眼 MSR。每眼為第一次 MPMVA、紅綠、JCC、第二次 MPMVA。自然差異病例從一開始就有固定的檢影調節／測量偏移，主覺終點不會到 JCC 時突然更改。可存檔、繼續與下載紀錄。

2D 儀器依最新參考照片重整，保留直接拖曳：**大球面輪向上加負、向下加正，每格 0.25D**；強球旋鈕另為 3.00D。球面讀數窗在兩側外輪緣，負數紅字。柱面與軸為同軸旋鈕；軸盤固定、0／180 在水平，外圈兩端對稱紅箭頭連續旋轉，可跨零點轉多圈。PD、水平氣泡、額托 VD 可調。JCC 的放入／收回與 A/P 獨立；支桿可拖到窺孔前。旁邊的詢問鍵自動展示「這是 1／這是 2／哪一個清楚」及患者回答；問答字幕顯示在儀器中央偏下。O／OC 實際改變遮蓋、視野及能否作答。檢影光條用左右拖曳的水平套筒輪操作，不使用滑動桿。

**2D 快捷操作**：左側可收合的「VA 相關」提供檢影後雙眼 VA（含 ±字數）、OD／OS 第一次 MPMVA、逐眼紅綠、OD／OS／雙眼第二次 MPMVA。MPMVA 按鈕模擬量測，只改指定眼球面、保留柱面與軸；第二次不自動做紅綠。紅綠由使用者自行調鏡，連續兩次實際加負均回綠時，提示自行退回一格負鏡，不替使用者退鏡。上方可偷看處方；EXAMINATION 在快捷操作下方並可收合。這些快捷操作只適用 2D 模式。

**使用者指定暫緩**：旋轉稜鏡、R（+1.50／+2.00 檢影鏡片）、P 偏光、WMV／RMV、內建 ±0.50 與 ADD。外掛 ±0.25 JCC 不在暫緩清單內。完整紀錄見 `Documentation/PRACTICE_MODES.md`、`SESSION_NOTES.md` 與 `Reports/PRACTICE_ACCEPTANCE.md`。

這兩頁可 file:// 離線使用；患者反應仍是教學近似。圖卡與外觀有來源依據，但未經實機投影亮度、實體遮罩孔徑及視角標定，不宣稱與實機所有物理特性完全一致。

修改 2D 圖面／控制後執行：

```powershell
node tools/build-practice-assets.mjs
node tools/verify-practice-models.mjs
node tools/verify-site.mjs
```

`docs/modes/instrument-svg.js` 為新儀器圖面；其他光學、旋鈕與檢影從 repo 的既有 2D 程式抽離，不載入舊 3D 引擎。`assets/legacy-instruments.js` 是產出檔，請改來源後重建。型錄圖卡的原廠來源與重建方式在 `docs/modes/assets/SOURCES.md`。

## 範圍

只做期中，順序依期中紀錄單：前置九項（含消毒儀器與 PD 尺、PD 對應邊緣法）→ ① 雙眼檢影 → 扣工作距離 → 右、左眼以淨檢影值測 VA 並記錄 → ② 右、左眼各做霧視／第一次 MPMVA（記錄度數與 VA）＋紅綠 → ③ 右、左眼 JCC APA／PPAP 並記錄 → ④ 右、左眼第二次 MPMVA（記錄度數與最佳 VA）。病歷版面同紀錄單。

**不含鐘面圖、雙眼平衡、AA、NPA、NPC 或其他期末項目。**

教學模式有過關條件與下一個動作；自由練習可查看參考病例；考試模式為 18 分鐘、隱藏提示，完成後提供回饋。六個可重現病例，包含近視與遠視散光。進度存於瀏覽器，選單可繼續上次練習，病歷可以下載為文字檔。

## 重建

Windows 已安裝 Unity **6000.6.5f1（含 WebGL Support）**、Blender 5.2，Python 需 fonttools。以 PowerShell 執行：

```powershell
./tools/build.ps1
```

也可在 Unity 選單依序執行 `Clinic > Validate clinical model`、`Clinic > Generate scene`、`Clinic > Build WebGL`。Unity Build 會重建場景並執行 C# 臨床邏輯檢查。場景、儀器與工具的 Blender 模型為自行建立，病人與手形來自 MakeHuman CC0 素材（見下方「人物模型來源」），字型為 SIL OFL 1.1 的 Noto Sans CJK TC（附字型授權及產生子集工具）。

本機可用 `python -m http.server 9035 --directory docs`，瀏覽器開 `http://127.0.0.1:9035/`。WebGL 使用 gzip + Unity decompression fallback，GitHub Pages 不需自訂 Content-Encoding headers。

## 驗證與限制

光學以雙角功率向量計算。JCC 使用 ±0.25D，負柱面每增加 -0.50DC 自動補 +0.25DS；工作距離只從球面扣除。檢影反射與 JCC 回答由當前鏡片決定，不依任務編號給固定答案。臨床模型測試涵蓋六病例、軸位邊界、兩子午線中和、紅綠方向、PH、等效補償及更動鏡片後紀錄失效。

這是**風格化 3D 教學模擬**，模糊、調節與患者回答為近似模型；不等同真實病人的反應，也不能輸出臨床處方。儀器為剛性分件、人物為簡單蒙皮（頭、下巴、上眼瞼、手指），皆由 Unity 程式動畫驅動，並非真人動作捕捉。未聲稱涵蓋所有眼科檢查或全部驗光設備。

實際完成的建置與瀏覽器檢查請看 `Reports/ACCEPTANCE.md`。每次工作交接請先讀 `AGENTS.md` 和 `SESSION_NOTES.md`。

## 遙控器與 JCC（2026-10-15 操作改版）

拿到遙控器或完成紅綠視標準備後，左下角常駐長形遙控器：E／紅綠／點陣、0.1–1.2 視力列、大／小一列、復位（E 字 0.6）與投影開關。外觀參照使用者照片，但僅提供本專案已模擬的期中功能。投影關閉時不能讀表；拿取狀態隨病例存檔。

JCC：按住外側支桿沿轉盤圓弧拖曳，放開後吸附到窺孔或收回位置。鏡片中央點擊切 A／P；中央或兩側滾輪上滾動滑鼠，每次翻一面，第二次回翻完成一次比較。空白鍵仍執行完整兩面詢問。

## 背景音樂與 ESC 選單

背景音樂為使用者提供的「Blue Oiia - Uiia Cat.mp3」，瀏覽器第一次點擊或按鍵後開始循環播放。ESC 可調整音量（預設 20%，0% 靜音，跨次保留）、繼續、保存進度回主選單或放棄這輪。放棄前會再確認，只清除這輪存檔；音量與工作距離偏好保留。暫停時驗光動作及計時停止，背景音樂繼續。

## 人物模型來源（2026-10-16）

病人身體、臉、頭髮、眉毛、睫毛、衣服（白 T 恤＋牛仔褲）、鞋子與雙手的手形，來自 MakeHuman 的 **makehuman_system_assets（CC0 1.0）**，用 Blender 擴充 **MPFB 2.0.18**（GPL 授權，只當產生工具使用，沒有放進本專案或網站）產生。眼睛（鞏膜、虹膜、角膜緣、瞳孔、反光點）仍是本專案自製，尺寸對準新臉的眼窩。手套為單色材質。重建前需在 Blender 安裝 MPFB 並載入該素材包；`tools/build.ps1` 會依序跑 build_clinic.py 和 build_people.py。

## 新手操作教學

主選單「新手操作教學」會用金色外框與箭頭一步步帶過所有操作（走路、轉頭、工作距離、拿工具、旋鈕、遮蓋、遙控器、詢問、檢影、霧視、紅綠、JCC、記錄、病歷、選單），桌機與平板各有對應說明；教學不會覆蓋「繼續上次練習」的存檔。
